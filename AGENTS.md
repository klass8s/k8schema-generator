# Agent guide

k8schema-generator is a Symfony console application that generates the PHP classes of k8schema from
the JSON schema of the Kubernetes API. This file is for coding agents;
[CONTRIBUTING.md](CONTRIBUTING.md) says the same for people and describes how the code is organised,
and where the two differ, CONTRIBUTING.md wins.

## What a pull request must satisfy

- It targets `main`, never the branch of another open pull request.
- `composer cs:check` passes (`composer install -d tools/php-cs-fixer` installs the tool once).
- The description shows what the change does to the generated code for at least one Kubernetes
  minor (`bin/k8schema-generator schema:fetch` and `generate`, before and after, and the diff). A
  change that deletes generated classes, properties or methods is a breaking change and is marked as
  one.
- The title and every commit are [Conventional Commits](https://www.conventionalcommits.org)
  (`type(scope): subject`, `!` for a breaking change to the generated code); each commit has a body
  that says what changed and why. Pull requests are squash-merged: the title becomes the commit on
  `main`.
- Generated code is never committed here: it lives in k8schema, regenerated by its workflow.
